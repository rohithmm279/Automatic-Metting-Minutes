Dataset Collection and Description

The project uses a combination of public benchmark datasets, meeting-dialogue datasets, question-answering datasets, and a project-specific student-club meeting dataset. These datasets were collected from official dataset repositories, GitHub repositories, research dataset platforms, and, for the final project evaluation dataset, generated specifically for this project.

1. AMI Meeting Corpus

Dataset name: AMI
Dataset type: Meeting transcripts and annotations
Source: AMI Meeting Corpus official website
Collection location: University of Edinburgh Informatics / AMI Corpus website
Source URL: https://groups.inf.ed.ac.uk/ami/download/
License: Creative Commons attribution is indicated in the project inventory, but independent license verification has not yet been completed.
Acquisition status: Not downloaded
Raw size: 0 B
Processed size: 0 B
Number of meetings: 0 acquired
Transcripts: Unknown because the dataset was not downloaded
Summaries/actions/decisions/issues: Not locally verified

Description

The AMI dataset is a well-known meeting corpus designed for research on meeting understanding, dialogue processing, summarization, and information extraction. The source contains recorded meeting material together with transcript and annotation resources.

For this project, AMI was considered because it is highly relevant to the task of converting meeting discussions into structured outputs such as summaries and action items.

Collection status in this project

The dataset was not acquired into the project environment. The source host was inaccessible from the sandbox because access was blocked with an HTTP 403 network restriction.

Therefore, the report should state:

AMI was identified as a relevant external benchmark dataset, but the complete dataset was not incorporated into the local experimental dataset because the official download host was inaccessible from the project environment.

2. QMSum

Dataset name: QMSum
Dataset type: Meeting summarization and question-answering
Source: Yale-LILY GitHub repository
Collection location: Yale-LILY research repository on GitHub
Source: https://github.com/Yale-LILY/QMSum
License: MIT
Acquisition status: Fully acquired
Raw size: Approximately 120 MB
Processed size: Approximately 2 MB
Number of meetings: 232
Number of examples: 1,810
Transcript: Yes
Summary: Not included as a direct dataset field in the project representation
Actions: No
Decisions: No
Issues: No
Evidence/relevant spans: Yes
Official split: Train / validation / test

Description

QMSum is a meeting-focused question answering and summarization dataset. It is particularly useful for evaluating whether a system can understand long meeting conversations and retrieve or summarize information relevant to a particular query.

Unlike a simple summarization dataset, QMSum emphasizes query-based understanding of long meeting transcripts. This makes it useful for studying how an AI system identifies specific information from lengthy discussions.

Collection

The dataset was downloaded from its official GitHub repository and processed locally for project use. The project retained the dataset's official train, validation, and test splits.

Relevance to your project

QMSum is useful for:

meeting transcript understanding
long-context processing
information extraction
evidence-grounded generation
evaluation of meeting-related language models

However, QMSum does not directly provide your full target structure of task + owner + deadline + decision + issue, so it is primarily useful as a meeting-understanding benchmark rather than a direct action-item dataset.

MeetingBank was investigated as a benchmark for long-form meeting-minutes generation. The associated GitHub utility repository was acquired, but the actual dataset could not be incorporated because its external hosting sources were inaccessible from the project environment.

For this project, an important characteristic is that the dialogues use meeting identifiers associated with AMI/ICSI-style meeting data.

The project inventory specifically records a correction:

The meeting IDs are based on AMI/ICSI formats, rather than QMSum as originally assumed.
